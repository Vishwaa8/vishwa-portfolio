## Overview

A modern, responsive personal portfolio showcasing my professional experience, academic background, selected projects, and expertise in software development and project management.

Built with Next.js and TypeScript, the website features a minimal black-and-white aesthetic, intuitive navigation, and a seamless experience across desktop, tablet, and mobile devices.

## Live Website

**[vishwa-udhantha.vercel.app](https://vishwa-udhantha.vercel.app/)**

## Key Features

- Modern and minimal black-and-white design
- Fully responsive desktop, tablet, and mobile layouts
- Light and dark theme switching
- Sticky navigation with automatic active-section highlighting
- Smooth scrolling between sections
- Professional experience timeline
- Featured project showcase with browser mockups
- Interactive project filtering
- Resume viewing and downloading
- Direct Gmail integration
- Copy-to-clipboard email functionality
- Social media and professional profile integration
- Static architecture without a dedicated backend

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/Vishwaa8/vishwa-portfolio.git
cd vishwa-portfolio
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
```

## Deployment

The portfolio is hosted on Vercel and connected to the GitHub repository for continuous deployment.

Changes pushed to the `main` branch automatically trigger a new deployment.

No dedicated backend, database, or environment variables are required.
